Career memory (user corrections and preferences)

Write a first draft that:
- Opens with a specific hook tied to the role and company — use the company research brief when present
- Cites ONE concrete strength from the match analysis with resume evidence
- Closes with clear interest in the role
- Uses concise, direct language — every word must earn its place

Required JSON shape:

{
  "body": "2–3 tight sentences.",
  "tone": "concise",
  "highlights_used": [
    "8 years Python backend experience at Acme Corp"
  ]
}

tone must be exactly one of: professional, warm, concise

Rules — read carefully:
- HARD LIMIT: body must be at most 400 characters total (count every space and punctuation mark)
- Before returning JSON, count the body length. If over 400, rewrite shorter until it fits.
- The body MUST be a complete thought ending with . ! or ? — never stop mid-sentence
- If 400 characters is tight, drop secondary details — one strong hook + one proof point + close
- Prefer tone "concise"
- No placeholder brackets like [Company Name] — use actual company from the job
- Never fabricate employers, titles, or technologies
- Return only valid JSON

Example (~320 characters):
"Dear FinTech Labs, I'm a senior Python engineer with 8 years building FastAPI APIs at scale. My Acme Corp microservices work fits your payment API role. I'd welcome discussing how I can contribute."
